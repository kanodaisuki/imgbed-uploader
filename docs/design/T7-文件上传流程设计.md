## 1. 范围

`uploadFile` 命令真实现：命令面板（文件选择框多选）与资源管理器右键（选中文件直传）→ 逐个上传（T2）→ 按 FR-4 插入细则在光标行插入 `![](url)`（每文件独立一行）→ 部分失败报告与重试（4.4）。**不做**：文档内引用解析与回写（FR-1/2，T6）、粘贴（T9）、远程转存（FR-5，T10）。

## 2. 方案与取舍

### 2.1 两入口收束一个编排函数

handler 层只负责**取文件列表**（命令面板 `showOpenDialog` 多选 / 资源管理器菜单参数 `(uri, uris)`），统一交给 `uploadLocalFiles(editor, uris)` 编排：前置检查 → 逐个上传（进度/取消）→ 单次编辑插入 → 报告。FR-4 要求两入口「行为一致」——细则只写一处。

- ❌ 被否：两个入口各写一套——插入细则/报告重复，行为必然漂移

### 2.2 插入细则落纯函数：单个插入点，一次编辑

`planFileInsert(text, cursorLine, links)` → 单个 `{ offset, insert }`，细则：

- 光标行**非空** → 下一行独立一行：块插到下一行行首（光标行为文末行 → 追加换行 + 块）；
- 光标行**空行**（含纯缩进）→ 就地：首链接落该行行尾（行首前缀保留），其余逐行向下（新行插入，不触碰后续内容）；
- 多选按**文件选择顺序**（= picker 返回顺序 / 资源管理器 `uris` 数组顺序）逐行排列；
- 插入行前缀 = 光标行**内容列之前的全部字符**（行首空白 + `>` 引用标记链 + 列表 marker）原样复制——`- 项目` / `> 引用` 下一行插图不破格（仅跟随空白缩进会跌出列表/引用，评审 P1）；标记行（trim 后非空，如 `- ` 空列表项）按**非空行**走下一行新列表项，不做「就地填入」（二次评审钉口径）；EOL 跟随文档（CRLF 检测）；
- 光标行与全文在**插入时**取（`editor.selection.active.line` + `doc.getText()`，与 §6 重试「动作发生在当下」同口径）；取值入口统一判 `editor.document.isClosed`——已关闭则**报告照出、链接不插入**（提示「文档已关闭，链接未插入」），主流程与重试走**同一道关卡**（二次评审）；`planFileInsert` → 构造 `WorkspaceEdit` → 调用 `applyEdit` 为**同步原子段，不得夹 `await`**（T6 §2.3 同红线：上传耗时长，中途用户编辑会让插入错位，评审 P1）；
- **纯插入零删除**（空行就地场景也只在行尾追加）——与 T5「URL 之外零触碰」同红线；单个插入点 = 一次编辑 = 一次 Ctrl+Z（与 4.7 单次提交同精神）。

- ❌ 被否：逐个 `applyEdit` 流式插入——多次撤销、且中途用户编辑会让后续插入错位；「逐行插入」指每文件独立一行的**版式**，不是流式语义
- ❌ 被否：插到光标字符处（`selection.active` 字符位）——FR-4 明确「光标行的下一行独立一行 / 空行就地」，按行不按字符

### 2.3 上传：逐个串行（FR-4 字面），复用 T6 `runUploads` 并发 1

顺序 = 文件选择顺序；`runUploads` 加可选并发参数（默认 3、行为不变、T6 现有测试不动，T6 变更记录登记），T7 传 1 即串行——进度「第 x/y 张」、取消只停派发、结果聚合、顺序保持全部白拿，不养第二份进度/取消语义（评审 P2）。取消后**已成功的照常插入**（与「已成功的保留回写」同口径），未开始的跳过；失败项跳过并入报告。文件读取走 `vscode.workspace.fs` **直读 picker/菜单给的原始 `Uri`**：`source.path` = `uri.fsPath`（保证 `baseName` 出正确文件名），`io.readLocal` 经 fsPath→Uri 映射回原始 Uri——**不走 T6 的 doc.uri 派生**（跨 authority/跨盘符会读错），也不用 `uri.toString()` 当 path（`baseName` 会把 `%20` 带进上传文件名）（二次评审）。

- ❌ 被否：T7 自写串行循环——进度/取消/结果聚合约 40 行近复制，此后语义改动要同步两处；原被否理由「FR-4 明文逐个上传」由并发参数 1 满足，串行语义不变

### 2.4 URL 安全化复用 T5：`markdownText` 转导出

插入的 `![](url)` 是 markdown 行内链接：URL 含空格/括号等必须走 T5 §2.3 的 `<>` 包装规则，否则同样是「用正确数据写出坏文档」。T5 的 `markdownText` 本为内部函数（「不导出，避免为测试扩大导出面」）——本任务出现真实的跨模块需求，**调整为导出**（T5 变更记录登记）；插入文本 = `![](${markdownText(url)})`。

- ❌ 被否：T7 重写一份编码规则——两处规则漂移（T5 的 21 项安全化矩阵就白测了）
- ❌ 被否：全量百分号编码后裸写——同 T5 被否理由（URL 文本失真，违「回写的就是拿到的链接」）

### 2.5 报告与重试复用 T6 体系（4.4 适用于 FR-1~5）

`ui.showReport` 原样复用：计数按文件、明细进 Output Channel、401/403 附「重新设置认证信息」。「重试失败项」= 闭包重传失败文件并插入其链接（与 FR-1 的 `onlyKeys` 并列的第二种重试形态，直接复用本次 `uris` 子集）；回调走 §2.2 同一道 `isClosed` 关卡（已关闭则提示「文档已关闭，请重新执行命令」并退出）——不向已关闭文档 `applyEdit`（offset 按旧 buffer 计算，会写坏磁盘文件，评审 P2；主流程同窗口的防护见 §2.2，二次评审）。FR-4 无策略跳过项（选了就试），摘要「跳过 k」仅计取消未开始。

### 2.6 入口细则

- 命令面板：`showOpenDialog({ canSelectMany: true, filters: { 图片: IMAGE_EXTENSIONS } })`——扩展名与 4.1 粗筛**同源**（parse.ts 导出 `IMAGE_EXTENSIONS`，粗筛正则改由其构造，防两处清单漂移）；取消选择框 → 静默退出。
- 资源管理器右键：菜单参数 `(uri, uris)`，多选取 `uris`，回退 `uris ?? (uri ? [uri] : [])`（程序化触发只传 `uri` 时不走空，评审 P3）；回退后仍为空（零参触发）→ 与选择框取消同径**静默退出**，不出零值报告（二次评审）；`when` 子句 T1 已配（package.json 无需改动）。
- 无活动 Markdown / MDX 编辑器（如资源管理器右键场景）→ 提示先打开目标文档，**不新建文档**（FR-4）；命令面板可在任意语言下触发，同此判定（目标编辑器须 `markdown`/`mdx`）。
- ❌ 被否：picker 放开全部文件类型——入口语义是「上传本地图片」；格式权威裁决仍在服务端（4.9），手动输入文件名仍可到达，不额外拦截

## 5. 测试方式

`planFileInsert` 纯单测（splice 全文逐字对比，T5 同法）：

- **光标行非空**：中间行 → 下一行插块；文末行（有/无尾换行）→ 追加不吞既有换行。
- **光标行空行**：就地 + 后续逐行；纯缩进行就地保留缩进，后续行同缩进；空行 + 文末无尾换行 → 首链接落行尾，其余补 EOL 开新行（与「非空文末行」不同代码路径）。
- **前缀复制**：`- 项目` 下一行 → `- ![](url)`；`> 引用` 下一行 → `> ![](url)`；`> - 项目` 下一行 → `> - ![](url)`（列表/引用不破格，评审 P1 修复项）；组合链缩进 `  > - 项目` → `  > - ![](url)`；负例：纯文本行 `文本` → 前缀空、不复制任何标记；`- ` 空列表项行按非空行走下一行新列表项（§2.2 口径）。
- **多选顺序**：3 链接按文件选择顺序逐行排列；单链接一行。
- **EOL**：CRLF 文档插入保持 CRLF。
- **零删除红线**：结果全文 = 原文 + 纯新增（空行就地场景不删缩进空白）。
- **全失败**：links 空 → 不产生编辑，全文不变。
- **安全化组合**：含空格 URL 经 `markdownText` → `![](<...>)` 形态，插入后全文合法。

壳层 `uploadLocalFiles` 归 T11 集成（mock 图床）：两入口取文件列表、插入位置、取消后已成功照常插入、失败报告与重试、无活动 md/mdx 编辑器提示。手动走查（T11）：FR-4 无专条验收，过两个入口与插入细则。

## 6. 边界说明

- 多光标/多选区：取主光标（`selection.active` 所在行）；有选区时同（FR-4 按光标行，与 FR-2 选区语义无关）。
- untitled Markdown 编辑器可插入（FR-4 无路径解析，与 FR-1 的 4.8 不同）。
- 「重试失败项」的插入位置 = 点击时的当前光标行（动作发生在当下，不回溯原插入点）；需贴回原批量旁时手动定位。目标文档已关闭 → 提示重新执行命令，不向已关闭文档 `applyEdit`（§2.5）。
- 非图片文件（when 子句拦不住命令面板全量触发）→ 上传由服务端裁决（4.9），失败进报告。
- 同一文件选中两次传两次（FR-4 无去重语义，4.6 只约束文档内引用）。
- 同 fsPath 异 scheme 的文件碰撞（极端）：fsPath→Uri 映射取先到者、读到同路径内容——已知边角，接受（§2.3 读取 seam）。
- 插入纯新增、零删除：不触碰既有任何字符（§2.2 红线）。
- package.json 的 `when` 扩展名正则是静态副本，与 `IMAGE_EXTENSIONS` 无法共享——清单变更需两处同步（成本极低，接受）。
- 多选大文件批量：串行 + 60s 超时（T2）；升级时机：确有用户批量大图卡顿时改并发。
